# IEEE Website

This is the official website for the IEEE Student Branch at VESIT (Vivekanand Education Society's Institute of Technology). Built with React and Vite, it serves as a comprehensive platform for information about the IEEE chapter, including council details, events, workshops, societies, and membership.

## Features

- **Home Page**: Overview of IEEE activities and announcements.
- **Council Pages**: Information about current and previous council members.
- **Events**: Details on upcoming and past events.
- **Workshops**: Dedicated pages for various technical workshops like UI/UX, Flutter, Machine Learning, etc.
- **Societies**: Sections for WIE (Women in Engineering) and other societies.
- **Membership**: Information and forms for joining IEEE.
- **Contact**: Contact details and links.
- **Calendar**: Event calendar integration.
- **Responsive Design**: Optimized for desktop and mobile using Tailwind CSS.

## Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Icons**: React Icons
- **Animations**: React Countup, React Intersection Observer
- **Email Integration**: EmailJS
- **Image Processing**: Sharp (for WebP conversion)
- **Linting**: ESLint
